# operacion/

Tareas locales sobre el contenido de los usuarios (`datos/valoraciones.db`). No entran a la imagen de
Render.

- `exportar_valoraciones.py`: exporta calificaciones y comentarios a CSV en `extracto/`.
- `moderar_comentarios.py`: lista comentarios y borra el de alguien más (`--borrar ID`).

No va aquí: revisiones de calidad (`calidad/`) ni nada que cambie el modelo o el catálogo.
