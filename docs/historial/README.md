# docs/historial/

Cómo se llegó aquí: los planes y las revisiones por fase, la mejora 01 (con los criterios que se fijaron
antes de correr sus pruebas) y los mockups HTML de la fase 6. Sirve para entender una decisión pasada, no
para correr el proyecto.

Las rutas que aparecen en estos archivos son las de cuando se escribieron, antes de que el Python se moviera
a `backend/` y los notebooks a `notebooks/`. No se corrigen, para que cada plan siga diciendo lo que decía.

- `fase-6-revision-usuario.md` y `reorganizacion-5-vistas.md`: planes de la interfaz.
- `mejoras/01-antes-del-reembolso.md`: la ficha de la mejora 01. Su resultado está en
  `docs/evidencia/antes-del-reembolso.md`.
- `mockups/`: los mockups y `capturar_mockup.py`, que los captura en tres anchos y dos temas (las capturas
  no se versionan).
